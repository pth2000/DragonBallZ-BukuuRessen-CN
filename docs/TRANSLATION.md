# 翻译规范

## 数据文件

剧情译文位于：

```text
data/translation/story_zh.tsv
```

界面译文位于同目录的 `ui_*.tsv`。所有表格均使用 UTF-8 编码和 Tab 分隔。

剧情表字段：

| 字段 | 用途 |
| --- | --- |
| `ID` | 稳定条目编号 |
| `脚本` | 路线或角色脚本代码 |
| `剧情块` | 剧情块索引 |
| `事件ID` | 游戏事件 ID |
| `指令序号` | 剧情块内的指令索引 |
| `指令` | 文本 opcode |
| `简体中文` | 构建输入 |

定位字段用于将译文写回原脚本，不得手工修改。公开表只保留构建所需的定位信息和中文结果；原文提取数据和内部审校记录不属于发布源码。

## 文本规则

- 行内换行写成字面量 `\n`，不得在单元格中插入真实换行。
- 使用既有中文标点风格：`，。！？：“”……（）`。
- 角色称谓、招式和系统词遵循[术语表](GLOSSARY.md)。
- 风格化英文、Logo、角色罗马字名和制作人员名单按原版保留。
- 避免行首标点；对白每行通常不超过约 20 个全角字符。

## 固定容量

剧情文本写回原有固定长度命令。构建器会计算实际编码长度；超出容量时立即失败，不会静默截断。

```powershell
uv run python tools/check_translation.py <原版 ROM>
```

出现超长条目时，应优先精简句式、删除冗余主语或调整分页。不得通过修改剧情块或指令定位字段绕过容量检查。

## 术语与审校

```powershell
uv run python tools/check_glossary.py
```

翻译变更应同时检查：

- 《龙珠》官方简体中文常用译名及术语表中的既定译法；
- 角色、形态、招式和系统词在剧情与界面中的一致性；
- 人物语气和上下文；
- 低分辨率字体中的可辨识度；
- 模拟器及真实硬件上的换行、字距和基线。

新增字符或标点时，还必须按[字库工作流](tech/FONTS.md)检查地区字形、映射槽和垂直基线。
