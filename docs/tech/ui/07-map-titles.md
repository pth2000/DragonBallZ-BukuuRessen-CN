# 地图标题

剧情、教学和 MAXIMUM 路线的关卡标题条，共 19 条路线、232 个标题，分布在 66 张纹理上，是图片界面中规模最大的本地化阶段。

```text
romdata/scene/maptitle_jp_tex.bin
```

## 资源结构

每条路线包含 5 张纹理和 1 张调色板：

```text
titlebar_<route>_00.ntft .. titlebar_<route>_04.ntft
titlebar_<route>_00.ntfp
```

纹理为 256×64 的 4bpp 线性像素，内部纵向排列 4 条标题，每条占 16 像素高。同一路线的 5 张纹理共用 `_00.ntfp` 这一张 16 色调色板。

这 5 张纹理是最多 20 个互相独立的标题槽。每个槽存放一条完整标题，可单独替换，不影响同一纹理上的其余三条。

槽位允许留空。部分路线的尾部保留了开发期的占位标题 `タイトルテスト`。

## 文字区域

单条标题从左至右依次为白方块图标、间隔和正文：

```text
x=0     白方块图标起点
x=13    图标右缘
x=18    正文起点
x=255   纹理右缘
```

正文原点为 `x=18, y=1`，与图标之间保留 4 像素净间距。垂直方向按可见笔画在 16 像素高的黑条内居中，理由见[排版规则](README.md#排版规则)。

## 本地化范围

19 条路线全部重绘，其中包含 MAXIMUM 的 60 个挑战标题。

同一纹理上的英文存在两种来源，处理方式相反，需要逐条区分。

第一类属于标题本身，例如 `SPARKING!!`、`MAXIMUM POWER`、`ULTIMATE BATTLE`、`Hope!` 和 `TEAM SATAN?`。它们占据标题槽、参与关卡选择，功能上即关卡名称，其中多数在日版语境中本就是外来语标题，因此纳入翻译范围。

第二类属于界面美术，包括白方块图标、槽位分隔线、空槽和占位标题，一律保持原样。

判定通则见[界面资源盘点](resource-audit.md)。

## 标点

翻译表中的全角 `！` 和 `？` 在本界面渲染为原版窄体 `!` 和 `?`。行高仅 16 像素，全角标点会占用过多横向空间，且与同一标题内的窄体字符风格不一致。

## 约束

除[通用约束](README.md#重绘约束)外，本界面追加以下检查：每条标题仅正文区域允许变化，白方块图标与分隔线逐点比对；未出现在翻译表中的槽位保持原始像素；同路线共用的调色板不变；66 张纹理重打包后解压回读，须与写入内容逐像素一致。

## 数据与构建

译文位于 `data/translation/ui_map_titles.tsv`，通过 `route`、`frame`、`row` 三个字段定位到具体的路线、纹理和行号。

```powershell
uv run python tools/build_map_titles.py
```

产物输出至 `build/ui_map_title_test/`，包括测试 ROM、相对原版的 BPS 和日/英/中三栏预览。

若仅需核对度量，可单独渲染原版的日文与英文标题：

```powershell
uv run python tools/render_map_titles.py    # build/map_title_audit/
```
