# 联机对战界面

联机对战的说明与连接提示。

```text
romdata/game/vsmode.bin
```

## 资源结构

该资源没有独立的 `JA/US` 文件名，六种语言的素材保存在同一个包内，以条目名后缀区分。因此按区域文件名进行的审计不会发现它，需要逐条检查包内条目才能定位到日文组。

`obi_j` 与 `msg_j` 的 NBFS 为 4096 字节，由两个 32×32 图块页组成，实际对应 512×256 的横向背景。构建器按原图块页顺序回写，并以真实横向布局生成预览；若按单页 256×256 预览，一句话会被从中间截断。

## 本地化范围

7 项文字，分三组：

| 条目 | 内容 |
| --- | --- |
| `msg_j` | 发起对战、加入已创建的对战、挑战所选对手 |
| `obi_j` | 无法继续显示更多联机对手的横条提示 |
| `vsmsg_j` | 等待连接、连接失败、按 A 键确认 |

`VS BATTLE` 标题、连接窗口、图标、调色板和其他五种语言组保持不变。

## 排版

文本块整体居中，块内多行左对齐。

## 数据与构建

译文位于 `data/translation/ui_vs_messages.tsv`。

```powershell
uv run python tools/build_vs_ui.py
```

产物输出至 `build/ui_vs_test/`，含按真实 512×256 布局排列的日/英/中三栏预览。
