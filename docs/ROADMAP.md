# 维护路线图

计划内的剧情和主要界面本地化已经完成。后续版本以质量保证、译文校对和兼容性维护为主，不默认扩大界面本地化范围。

当前覆盖范围与明确排除项见[项目状态](STATUS.md)。

## 优先级 P0：全流程验证

- 按 16 条角色路线和 IF 分支持续维护通关记录。
- 优先复核 62 条恰好占满原命令容量的文本；这些条目的措辞和断行余量最小。
- 覆盖 SKIP、快速推进、新游戏、普通存档和通关数据。
- 在 melonDS、DeSmuME 和真实硬件或烧录卡上交叉验证。
- 记录译文、称谓、断行、字形可读性和界面布局问题。

执行要求见[测试规范](TESTING.md)。

## 优先级 P1：术语一致性

所有译名变更必须同步更新 [`data/glossary/terms.tsv`](../data/glossary/terms.tsv)，并通过以下检查：

```powershell
uv run python tools/check_glossary.py
```

检查覆盖同名词条、翻译表引用和角色名在招式名中的一致性。当前版本没有登记例外。

## 优先级 P1：字形精修

- 按出现频率复核 895 个自定义字符和 32 个 Fusion 回退字形。
- 优先修整低分辨率下难以辨认的复杂字。
- 持续检查标点、地区字形和公共基线的一致性。
- 新增用字时重新验证编码槽，避免覆盖仍被使用的原生字符。

映射计划绑定当前翻译快照。扩充译文前必须重新核算剩余槽位，详见[字库工作流](tech/FONTS.md)。

## 暂不纳入的范围

以下内容维持原版状态，除非后续获得明确的用户价值和可靠实现方案：

- 角色选择中的其他动态文字与状态提示。
- 许可画面等低优先级资源。
- 制作人员名单和原版风格化英文美术。

审计结论见[界面资源盘点](tech/ui/resource-audit.md)。

## 条件性工程改进

现有定长写回方案已覆盖全部 3,100 条剧情文本。只有出现无法通过合理措辞解决的容量需求时，才评估变长脚本重排；该工作必须先确认块内跳转、外部指针和运行时缓存的完整行为。固定布局仍是当前构建稳定性的基础，详见[文件格式](tech/FORMATS.md#固定布局策略)。

## 发布要求

每个维护版本必须通过代码检查、核心测试、完整发布构建、公开目录检查和人工验证，并同步更新发布清单、哈希与已知问题。具体步骤见[发布流程](RELEASING.md)。
